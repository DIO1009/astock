## 1. 架构说明

```
┌─────────────────────────────────────────────────────────────┐
│  Linux 云服务器                                              │
│  ┌─────────────────────────────────────────────────────┐  │
│  │  bin/paper_trader  （单进程）                          │  │
│  │    ├─ 交易引擎（engine）                             │  │
│  │    ├─ 行情 provider/eastmoney                        │  │
│  │    ├─ Dashboard :18099（静态前端 + WebSocket + API）  │  │
│  │    ├─ 每日选股调度（09:31 CST，需 DB）                 │  │
│  │    └─ 日报调度（15:10 CST，需 DB）                     │  │
│  └─────────────────────────────────────────────────────┘  │
│  PostgreSQL :5432（本机）                                    │
└─────────────────────────────────────────────────────────────┘
         ▲ SSH 隧道（仅本地 18099，不对公网开放）
         │
   本地浏览器 http://localhost:18099
```

| 脚本 | 平台 | 说明 |
|------|------|------|
| `scripts/start.sh` | macOS | 依赖 `caffeinate` |
| `scripts/start_server.sh` | Linux | 云服务器专用，见下方默认参数 |
| `scripts/stop.sh` | 通用 | 停止进程并保留持仓快照 |
| `scripts/reset_server.sh` | Linux | 清空 DB + 本地状态后调用 `start_server.sh`（需确认或 `--yes`） |

**`start_server.sh` 内置默认（未设 `config/server.env` 时生效）：**

| 变量 | 默认值 |
|------|--------|
| `ASTOCK_LIVE_DATA` | `1` |
| `ASTOCK_DYNAMIC_SCREENER` | `1` |
| `ASTOCK_MAX_POS` | `10` |
| `ASTOCK_TICK_SECONDS` | `300` |
| `ASTOCK_ROTATION_ENABLED` | `0` |
| `ASTOCK_EM_MIN_INTERVAL_MS` | `1000` |
| `ASTOCK_EM_MAX_CONCURRENCY` | `2` |

## 2. 服务器与网络要求

### 2.1 硬件与系统

| 项目 | 建议 |
|------|------|
| 系统 | Ubuntu 22.04 / Debian 12 |
| CPU / 内存 | 2 核 4GB 起；开启动态选股建议 4GB |
| 磁盘 | 20GB+（日志、DB、reports） |
| 时区 | 建议 `Asia/Shanghai`（日志与调度按 CST） |

```bash
sudo timedatectl set-timezone Asia/Shanghai
timedatectl
```

### 2.2 网络（重要）

- 服务器需能访问 **东方财富** `push2.eastmoney.com`（实时行情）
- 建议选 **中国大陆** 地域 VPS；海外节点易出现 EOF / 限流
- 部署后自检：

```bash
curl -I --connect-timeout 5 https://push2.eastmoney.com/api/qt/stock/get
# 应返回 HTTP 200 或带 body 的响应，不应长时间超时
```

### 2.3 依赖版本

| 依赖 | 版本 | 用途 |
|------|------|------|
| Go | ≥ 1.22（以 `go.mod` 为准，当前 1.25） | 编译 `paper_trader` |
| Node.js + npm | ≥ 18 | 构建前端 `dashboard/frontend/dist` |
| PostgreSQL | ≥ 14 | 持久化、动态选股、日报 |
| Python 3 + requests | 可选 | 仅回放模式下载 CSV（`scripts/fetch_data.py`） |

## 3. 安装系统依赖

以下以 Ubuntu 22.04 为例。

### 3.1 基础工具

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl build-essential
```

### 3.2 安装 Go

从 [https://go.dev/dl/](https://go.dev/dl/) 下载与 `go.mod` 匹配的版本，例如：

```bash
# 示例：Go 1.25（版本号以 go.mod 为准）
wget https://go.dev/dl/go1.25.0.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.25.0.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
go version
```

### 3.2.1 配置 Go 模块代理（中国大陆服务器必做）

默认 `proxy.golang.org` 在国内常 **i/o timeout**，编译前执行一次（写入 `~/.bashrc` 永久生效）：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.google.cn
go env GOPROXY GOSUMDB
```

阿里云 ECS 也可用：

```bash
go env -w GOPROXY=https://mirrors.aliyun.com/goproxy/,direct
```

验证能否拉依赖：

```bash
cd ~/astock_trade
go mod download
```


> Ubuntu 自带 `apt install nodejs` 往往是 **Node 12**，会导致 `SyntaxError: Unexpected token '?'`。务必用 NodeSource 安装 **20.x**。

```bash
# 查看当前版本（若 v12.x 必须升级）
node -v

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v && npm -v
# 期望：v20.x.x
```

### 3.4 安装 PostgreSQL

```bash
sudo apt install -y postgresql postgresql-contrib
sudo systemctl enable postgresql
sudo systemctl start postgresql
pg_isready -h 127.0.0.1
```

### 3.5（可选）Python — 仅回放模式需要

实时模式（`ASTOCK_LIVE_DATA=1`）**不需要** Python。若要用 CSV 回放：

```bash
sudo apt install -y python3 python3-pip
pip3 install requests
python3 scripts/fetch_data.py   # 生成 real_market_data.csv
```

## 4. 配置 PostgreSQL

### 4.1 创建用户与数据库

```bash
sudo -u postgres psql <<'SQL'
CREATE USER astock WITH PASSWORD '请替换为强密码';
CREATE DATABASE astock_trade OWNER astock;
GRANT ALL PRIVILEGES ON DATABASE astock_trade TO astock;
SQL
```

### 4.2 连接串格式

```
postgres://用户名:密码@主机:端口/数据库名?sslmode=disable
```

示例（本机）：

```
postgres://astock:你的强密码@127.0.0.1:5432/astock_trade?sslmode=disable
```

### 4.3 验证连接

```bash
export PGPASSWORD='你的强密码'
psql -h 127.0.0.1 -U astock -d astock_trade -c 'SELECT 1;'
```

### 4.4 表结构

**无需手动建表**。首次启动 `paper_trader` 时会自动执行 `store.Migrate()`，创建：

| 表名 | 用途 |
|------|------|
| `executions` | 成交明细 |
| `positions` | 持仓快照 |
| `equity_curve` | 权益曲线 |
| `risk_events` | 风控告警 |
| `system_status` | 系统状态 |
| `alpha_rankings` | 每日选股排名（动态选股） |
| `daily_reports` | 日报元数据 |
| `orders` | 预留 |

### 4.5 禁用数据库

若暂时不用 DB，设置：

```bash
export ASTOCK_DB_DSN="-"
```

影响：无持久化、无动态选股、无自动日报、重启后无法从 DB 恢复权益曲线。

```bash

```

## 6. 配置文件（JSON）

以下文件位于项目根目录 `config/`，**修改后需重启** `paper_trader` 生效。

### 6.1 `config/trading_cost.json` — 交易成本

| 字段 | 含义 | 默认值 |
|------|------|--------|
| `commission_pct` | 佣金费率 | 0.000235 |
| `stamp_tax_pct` | 印花税（卖出） | 0.0005 |
| `transfer_fee_pct` | 过户费 | 0.00001 |
| `min_commission` | 最低佣金（元） | 5.0 |

### 6.2 `config/safety.json` — 安全控制

| 字段 | 含义 | 默认值 |
|------|------|--------|
| `streak_half_position_at` | 连续亏损 N 笔 → 仓位减半 | 10 |
| `streak_position_scale` | 减半后的仓位比例 | 0.5 |
| `streak_freeze_at` | 连续亏损 N 笔 → 冻结开仓 | 15 |
| `streak_freeze_ticks` | 冻结持续 tick 数 | 12 |
| `base_max_total_pct` | 最大总仓位占比 | 0.8 |
| `abnormal_latency_ms` | 执行延迟异常阈值（ms） | 15000 |
| `abnormal_fill_rate_pct` | 成交率异常阈值（%） | 5.0 |
| `abnormal_window_ticks` | 异常统计窗口 | 200 |
| `abnormal_threshold` | 窗口内异常次数 → 暂停交易 | 100 |
| `status_every_n_ticks` | 安全状态日志间隔 | 10 |

### 6.3 代码内固定参数（需改代码）

以下在 `cmd/paper/main.go` 中硬编码，一般无需改：

| 参数 | 值 | 说明 |
|------|-----|------|
| `initialCapital` | 100,000 | 初始资金 |
| `dashboardAddr` | `:18099` | Dashboard 端口 |
| `indexSymbol` | `000001.SH` | 大盘指数（趋势过滤） |
| 止损 / 止盈 | 5% / 30% | 持仓管理 |
| 回撤档位 | 20/30/35/40% | 风控 Monitor |

## 7. 环境变量完整说明

所有运行时环境变量均以 `ASTOCK_` 为前缀（独立命令 `cmd/daily_alpha` 使用 `PG_DSN`，见下）。

### 7.1 数据源

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ASTOCK_LIVE_DATA` | `start_server.sh` 默认 `1`；`start.sh` 默认 `0` | `1` = 东方财富实时 API |
| `ASTOCK_TICK_SECONDS` | `start_server.sh` 默认 `300`；`start.sh` 默认 `300` | Tick 间隔（秒） |
| `ASTOCK_DATA_PATH` | （空） | 回放模式 CSV 路径，优先级高于 `real_market_data.csv` |

### 7.2 数据库

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ASTOCK_DB_DSN` | 见 `server.env.example` | PostgreSQL 连接串；`-` = 禁用 DB |

### 7.3 选股与持仓

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ASTOCK_DYNAMIC_SCREENER` | `start_server.sh` 默认 `1`；`start.sh` 默认 `0` | `1` = 动态选股（需 DB 有 `alpha_rankings`） |
| `ASTOCK_TOP_N` | `100` | 动态候选池 Layer2 数量 |
| `ASTOCK_TOP_LAYER1` | `200` | 全市场初筛 Layer1（内置调度器） |
| `ASTOCK_SCAN_TIMEOUT` | `300` | 选股 HTTP 超时（秒） |
| `ASTOCK_MAX_POS` | `start_server.sh` 默认 `10` | 最大同时持仓 |
| `ASTOCK_EM_MIN_INTERVAL_MS` | `start_server.sh` 默认 `1000` | 东方财富两次实时 HTTP 最小间隔（毫秒），防 EOF 限频 |
| `ASTOCK_EM_MAX_CONCURRENCY` | `start_server.sh` 默认 `2` | 实时行情并发数 |
| `ASTOCK_INCLUDE_ALL_BOARDS` | （未设 = 排除） | `1` = 包含创业板/科创板 |

**动态选股启用条件**（满足其一）：

- `ASTOCK_LIVE_DATA=1` 且 DB 连接成功（**自动**启用）
- `ASTOCK_DYNAMIC_SCREENER=1` 且 DB 连接成功

内置调度器：每个交易日 **09:31 CST** 自动全市场选股；启动时若当日无排名数据，会等到 09:30 后补跑。

### 7.4 轮动调仓（可选）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ASTOCK_ROTATION_ENABLED` | `0` | `1` 启用轮动 |
| `ASTOCK_ROTATION_START` | `09:45` | 允许轮动开始时刻 |
| `ASTOCK_ROTATION_WATCH_RANK` | `70` | 进入观察的排名阈值 |
| `ASTOCK_ROTATION_EXIT_RANK` | `85` | 触发换出排名 |
| `ASTOCK_ROTATION_CONFIRM_TICKS` | `3` | 确认 tick 数 |
| `ASTOCK_ROTATION_CONFIRM_DAYS` | `2` | 确认天数 |
| `ASTOCK_ROTATION_DELTA` | `0.10` | 换仓得分差阈值 |
| `ASTOCK_ROTATION_LOSS_MULT` | `1.5` | 亏损仓位差阈值倍数 |
| `ASTOCK_MAX_ROTATION_PER_DAY` | `3` | 每日最大轮动次数 |

### 7.5 调试

| 变量 | 说明 |
|------|------|
| `FACTOR_DIAG=1` | 下一合法 tick 仅输出因子诊断后退出，**不交易** |

### 7.6 独立命令 `cmd/daily_alpha`（可选手动选股）

一般不单独跑；paper 进程内置调度器。手动执行时：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PG_DSN` | 另一套默认 DSN | 应设为与 `ASTOCK_DB_DSN` 相同 |
| `TOP_LAYER1` | `200` | 同 `ASTOCK_TOP_LAYER1` |
| `TOP_LAYER2` | `50` | Layer2 数量 |
| `SCAN_TIMEOUT` | `300` | 超时秒数 |

```bash
export PG_DSN="$ASTOCK_DB_DSN"
go run ./cmd/daily_alpha
```

## 10. 本地访问（SSH 隧道）

**安全组 / 防火墙：只放行 22，不要开放 18099。**

### 10.1 一次性隧道

在本地 Mac/PC：

```bash
ssh -N -L 18099:127.0.0.1:18099 astock@你的服务器IP
```

浏览器：**http://localhost:18099**

### 10.2 SSH 配置（推荐）

本地 `~/.ssh/config`：

```
Host astock
    HostName 你的服务器IP
    User astock
    LocalForward 18099 127.0.0.1:18099
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

```bash
ssh -N astock
```

### 10.3 长时间保活（Mac）

```bash
brew install autossh
autossh -M 0 -N astock
```

### 10.4 API 示例（隧道建立后）

```bash
curl "http://localhost:18099/api/equity?range=7d"
curl "http://localhost:18099/api/positions"
curl "http://localhost:18099/api/executions?limit=20"
```

## 11. systemd 常驻运行

### 11.1 准备

```bash
bash scripts/start_server.sh --build-only
```

### 11.2 服务单元

`/etc/systemd/system/astock-paper.service`：

```ini
[Unit]
Description=AStock Paper Trading
After=network-online.target postgresql.service
Wants=network-online.target postgresql.service

[Service]
Type=simple
User=astock
WorkingDirectory=/home/astock/astock_trade
EnvironmentFile=/home/astock/astock_trade/config/server.env
ExecStart=/home/astock/astock_trade/bin/paper_trader
Restart=on-failure
RestartSec=15
LimitNOFILE=65535

# 日志
StandardOutput=append:/home/astock/astock_trade/logs/paper_trader.log
StandardError=append:/home/astock/astock_trade/logs/paper_trader.log

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable astock-paper
sudo systemctl start astock-paper
sudo systemctl status astock-paper
journalctl -u astock-paper -f   # 若需看 systemd 层日志
```

### 11.3 更新代码

```bash
cd ~/astock_trade
git pull
set -a && source config/server.env && set +a
bash scripts/start_server.sh --build-only
sudo systemctl restart astock-paper
```

## 12. 防火墙与安全组

### 12.1 云厂商安全组

| 端口 | 策略 |
|------|------|
| 22/tcp | 仅你的 IP 或 IP 段 |
| 18099 | **不要**对 0.0.0.0/0 开放 |
| 5432 | **不要**对公网开放 |

### 12.2 UFW（可选）

```bash
sudo ufw allow OpenSSH
```

### 12.3 安全提醒

- Dashboard **无登录鉴权**；公网暴露 18099 等于公开持仓与清仓按钮。
- 勿使用仓库内示例密码 `dmrxlbol123`。
- `config/server.env` 权限建议：`chmod 600 config/server.env`。

## 13. 日常运维

| 操作 | 命令 |
|------|------|
| 启动（脚本） | `source config/server.env && bash scripts/start_server.sh` |
| 停止 | `bash scripts/stop.sh` |
| 清空并重跑 | `bash scripts/reset_server.sh`（或 `bash scripts/reset_server.sh --yes`） |

| 查看日志 | `tail -f logs/paper_trader_*.log` |

### 人工干预（服务器上）

```bash
PID=$(pgrep paper_trader)
kill -USR1 $PID   # 停止开仓
```

也可在 Dashboard 控制面板点击对应按钮（需 SSH 隧道已连接）。

## 15. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `[DB] 连接失败` | DSN 错误 / PG 未启动 | 检查 `pg_isready`、密码、`server.env` |
| `[EastMoney] ... EOF` | 非交易时段 / 海外 IP / 网络 | 交易时段重试；换国内节点 |
| 动态选股未启用 | DB 未连或未设 `ASTOCK_DYNAMIC_SCREENER` | 确认 DB 日志；实时模式会自动启用 |
| `[Scheduler] 选股失败` | 开盘前 clist 无数据 | 等到 09:31 后看日志；调度器会自动重试 |
| `go build` 访问 proxy.golang.org timeout | 国内无法直连 Google | `go env -w GOPROXY=https://goproxy.cn,direct` |
| 前端构建 `Unexpected token '?'` | Node.js 过旧（常见 v12） | 用 NodeSource 装 Node 20，删 `node_modules` 重装 |
| WebSocket 连不上 | 隧道未建 / 用了 https 访问 | 用 `http://localhost:18099`；隧道需 `-L 18099:...` |
| 持仓浮盈全 0% | 非交易时段行情失败误更新 | 已修复：无行情时不刷新；重启或等下一 tick |
